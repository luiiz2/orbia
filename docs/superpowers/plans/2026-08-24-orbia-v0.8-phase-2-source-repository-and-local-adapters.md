# Orbia v0.8 Phase 2 — Source Repository and Local Adapters Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Phase 1 source records safely queryable from the Main process and provide local and managed-offline adapters without changing canonical media paths or exposing raw paths to the renderer.

**Architecture:** A repository maps the existing source tables to typed domain values and produces one batched, renderer-safe source summary query. A Source Manager owns Main-only adapter registration and read access. The first adapters use the existing read-only scanner and Node streams; no watcher, reconciliation persistence, resolver, player, OAuth, cache eviction, or provider write is introduced.

**Tech Stack:** Electron Main process, TypeScript, better-sqlite3, Node.js `fs`/`path`/`stream`, existing `ScannerService`, Vitest.

**Spec:** `docs/superpowers/plans/2026-08-24-orbia-v0.8-connected-library.md` sections 10, 12, 19, 25, 26, 29, 30, and implementation phases 3–4.

## Global Constraints

- Keep canonical course/module/lesson/resource rows and all legacy path columns unchanged.
- Never move, delete, overwrite, rename, or otherwise mutate user media.
- Keep raw filesystem paths, adapter locators, and stream handles in the Main process; IPC returns summaries only.
- Reuse the existing `ScannerService`; add no dependency and no second queue, scanner, or sync framework.
- Source summary reads must be batched; no per-card database query pattern.
- Local and managed-offline adapters must reject non-files and invalid byte ranges, and managed-offline paths must remain contained under an app-owned base directory.
- Finish every task with focused tests and `npm run typecheck`; finish this phase with lint, full Vitest, and build.

**Files:**

**Interfaces:**

- Consumes: Phase 1 `content_sources`, `source_roots`, `source_items`, and `canonical_source_links` tables; `DatabaseService.getDatabase()`.
- Produces: `SourceSummary`, a Main-only `SourceAdapter` contract, `SourceRepositoryService.listSummaries()`, `getSource(id)`, `getRoot(id)`, `getItem(id)`, `listItemsForCanonical(canonicalType, canonicalId)`, and `SourceManagerService.register(adapter)`, `getAdapter(provider)`, `listSummaries()`.
- A `SourceSummary` contains only `id`, `provider`, `displayName`, `availability`, `preferenceWeight`, `itemCount`, `linkedItemCount`, `availableItemCount`, `missingItemCount`, and optional `lastSyncedAt`; it contains no locator or filesystem path.
- The Main-only adapter contract defines `readonly provider`, `identifyRoot(locator)`, `reconcile({ root })`, `open(item, range?)`, and `probe(item)`. Define `ByteRange` as `{ start: number; end: number }`; `SourceReadHandle` as `{ stream: Readable; status: 200 | 206; mimeType?: string; totalSize: number; contentRange?: ByteRange; seekable: boolean }`; and `SourceChangeBatch` as `{ items: SourceAdapterItem[] }`, where each item has `locator`, `name`, `relativePath`, `size`, `availability`, and optional `mimeType`/`technicalMetadata`. `SourceRootIdentity` includes `providerRootIdentity`, `displayName`, `availability`, and optional `stableDeviceId`/`mountHint`. None of these Main-only stream types are exported through `OrbiaApi`.

- [ ] **Step 1: Write failing real-filesystem adapter tests**

Create a temporary root containing `Module/Lesson.mp4`, `Guide.pdf`, and a symlink if the platform permits it. Include these real stream helpers in the test:

```ts
async function collect<T>(iterable: AsyncIterable<T>): Promise<T[]> {
  const values: T[] = []
  for await (const value of iterable) values.push(value)
  return values
}

async function read(stream: NodeJS.ReadableStream): Promise<Buffer> {
  const chunks: Buffer[] = []
  for await (const chunk of stream) chunks.push(Buffer.from(chunk))
  return Buffer.concat(chunks)
}
```

- [ ] **Step 3: Implement the minimum read-only adapters**

Use `fs.promises.stat` to validate directory roots and regular files. `LocalFolderSourceAdapter.reconcile()` must call the existing scanner and flatten its discovered files into one deterministic batch sorted by normalized slash-separated relative path.
