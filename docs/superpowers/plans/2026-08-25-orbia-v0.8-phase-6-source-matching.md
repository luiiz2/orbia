# Orbia v0.8 Phase 6 Source Matching Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Match synchronized source items to canonical lessons/resources with explainable confidence, preserve ambiguous candidates for review, and support safe manual link/unlink actions.

**Architecture:** A pure `SourceMatcher` scores provider-neutral source metadata against canonical metadata without filesystem or provider calls. `SourceMatchingService` obtains Main-process-only metadata from `SourceRepositoryService`, persists candidate evidence, auto-links only unambiguous high-confidence matches, and leaves medium-confidence matches pending. Manual actions mutate only `canonical_source_links` and candidate status; they never touch user files or canonical organization.

**Tech Stack:** Electron Main process, TypeScript, better-sqlite3, Node.js standard APIs, Vitest.

**Status:** Implementado diretamente na branch `main`, com matcher, persistência de candidatos, links manuais, integração pós-sync e contratos IPC/preload.

**Spec:** `docs/superpowers/plans/2026-08-24-orbia-v0.8-connected-library.md` sections 18, 25, 27, 29, and 30.

## Global Constraints

- Never rename, move, overwrite, delete, or rewrite provider files.
- Automatic linking requires the same canonical course context; an unknown or different context can never auto-link.
- High-confidence links require strong content evidence plus compatible metadata and an unambiguous winner.
- Equal size/duration alone is medium confidence and remains pending review.
- Cross-course checksum/fingerprint equality is informational only and never creates a link.
- Persist `SOURCE_MATCH_THRESHOLD_VERSION` and path-free evidence for every stored candidate.
- Manual Link as Another Source and Unlink Source update only source-link/candidate rows.
- Renderer IPC exposes IDs, names, confidence, status, and evidence summaries; no locators, absolute paths, tokens, or provider payloads.
- Reuse the existing `source_match_candidates` and `canonical_source_links` tables; add no dependency.
- Work directly on `main` and keep the unrelated `vazados/` directory untracked.

## Self-Review

- Automatic links are source-link mutations only; canonical lesson/resource, Studio, progress, notes, and physical files remain untouched.
- Same-course context is an explicit gate; unknown context never auto-links.
- Strong evidence, medium evidence, ambiguity, and cross-course duplicates have distinct outcomes and persisted explanations.
- Candidate evidence is versioned and path-free at the IPC boundary.
- No provider network calls, playback, OAuth, resolver scoring, or cache behavior is introduced in this phase.
- No file under `vazados/` is inspected, changed, staged, or committed.
